# cofradometro
El Cofradómetro es una iniciativa de Sentir Cofrade | PTV Córdoba que convierte la Semana Santa en unas elecciones ficticias llenas de humor. Responde a 24 preguntas y descubre con cuál de los ocho partidos cofrades tienes mayor afinidad. Tradición, música, costaleros, arte y mucha guasa cordobesa. ¡Descubre tu ideología cofrade!
